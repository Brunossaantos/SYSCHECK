# Banco de Dados SYSCHECK

## 1. Visão Geral

O **SYSCHECK** é um banco de dados relacional projetado para suportar o sistema corporativo de controle operacional de **checklists**, **empilhadeiras**, **veículos**, **baterias**, **chamados técnicos** e **auditoria operacional**. O modelo foi estruturado para garantir rastreabilidade, histórico de uso, controle de responsabilidades e geração de indicadores.

O banco utiliza **MySQL/MariaDB**, com engine **InnoDB**, permitindo integridade referencial via **chaves estrangeiras**.

---

## 2. Entidades Principais

### 2.1 Usuários e Estrutura Organizacional

#### tbl_usuarios

Armazena os usuários do sistema.

* **ID_USUARIO (PK)** – Identificador único
* NOME – Nome completo
* DEPARTAMENTO – Departamento do usuário
* CARGO – Cargo ocupado
* NOME_USUARIO – Login
* SENHA – Senha (hash)
* STATUS_USUARIO – Ativo/Inativo
* TIPO_CHECKLIST – Tipo de checklist permitido

Relacionamentos:

* Referenciado por checklists, chamados, erros, uso de veículos e empilhadeiras.

---

#### tbl_departamentos

Define os departamentos da empresa.

* **ID_DEPARTAMENTO (PK)**
* DESCRICAO_DEPARTAMENTO
* STATUS_DEPARTAMENTO

---

### 2.2 Checklists

#### tbl_checklists

Registro principal de execução de checklists.

* **ID_CHECKLIST (PK)**
* FK_USUARIO → tbl_usuarios
* FK_TIPO → tbl_tipos_checklist
* FK_OBJETO → tbl_objetos
* DATA_INICIO
* DATA_FIM
* STATUS_CHECKLIST

Representa uma execução completa de checklist.

---

#### tbl_tipos_checklist

Tipos de checklist disponíveis no sistema.

* **ID_TIPO_CHECKLIST (PK)**
* DESCRICAO_TIPO_CHECKLIST
* FK_RESPONSAVEL → tbl_responsaveis
* STATUS_TIPO_CHECKLIST

---

#### tbl_etapas_checklists

Define as etapas que compõem cada tipo de checklist.

* **ID_ETAPA_CHECKLIST (PK)**
* FK_TIPO_CHECKLIST
* TITULO_ETAPA
* CONTEUDO_ETAPA
* NUMERO_ETAPA
* FOTO_OBRIGATORIA
* CAMPO_ADICIONAL
* STATUS_ETAPA

Exclusão em cascata ao remover um tipo de checklist.

---

#### tbl_etapas_realizadas

Registra a execução de cada etapa.

* **ID_ETAPA_REALIZADA (PK)**
* FK_CHECKLIST
* FK_ETAPA
* NUMERO_ETAPA
* ACAO
* OBSERVACAO

---
